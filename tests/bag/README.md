# tests/bag/ — recorded days, replayed deterministically

A **bag** is one recorded day of senses: a JSON file holding a header plus
an array of `HexyMsg` Sense dictionaries, sorted by `t_ns` (nanoseconds,
relative to 0 — the start of the recording, not a wall-clock epoch).

## Format

```json
{
  "version": 1,
  "name": "quiet_day",
  "dt_ms": 60000,
  "tick": 1440,
  "senses": [
    {"kind": "sense", "organ": "ocelli", "door": "lux", "t_ns": 0, "value": {"lux": 210.4}, "meta": {}},
    ...
  ]
}
```

- `dt_ms` — the simulated milliseconds between ticks the bag was recorded
  (and should be replayed) at.
- `tick` — how many ticks the bag covers (`dt_ms * tick` = the day's span).
- `senses` — every `HexyMsg.sense(...)` dictionary, sorted ascending by
  `t_ns`. Nothing here is wall-clock time; it is simulated time only, so a
  bag replays byte-identically no matter when or how fast it is played back.

## quiet_day.json / busy_day.json

Generated by `tests/bag/make_bags.gd` (a one-off `SceneTree` script, not
part of the automated suite): 24 simulated hours at one tick per 60
simulated seconds (1440 ticks), with a seeded `RandomNumberGenerator` so
regenerating produces byte-identical output. `ocelli` reports a lux value
every tick, following a coarse daylight curve (near-dark night, a dawn
ramp, full day, a dusk ramp); `halteres` imu bursts, `tarsi` touches, a
few `pheromone` peer pulses and a few `words` are sprinkled in at random
ticks. `busy_day` uses higher event probabilities and lux noise than
`quiet_day` so the two bags produce visibly different bodies.

## Recording a real day (later)

`scripts/core/bag.gd` (`HexyBag`) is the same format's writer:

```gdscript
var bag := HexyBag.new()
bag.record(topic, "my_real_day")   # subscribes to "/sense" on `topic`
# ... a real day happens, the phone's own senses publish on `topic` ...
bag.stop()
bag.save("user://my_real_day.json")
```

Every `t_ns` is made relative to the first sense recorded, so the saved
file is portable exactly like the generated ones. Play it back with
`HexyBag.load(path)` and `HexyBag.play(topic, senses, tick_cb, dt_ms, ticks)`
— see `tests/bag_replay.gd` for a worked example against a live brain.
